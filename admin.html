This edits your live catalog directly through GitHub — there's no separate admin password. A GitHub access token, scoped to just this one repository, is what proves it's really you.

Never shared with anyone but GitHub — it's kept only in this browser tab and is gone when you close it.

How do I get an access token?
  1. Go to github.com/settings/personal-access-tokens/new (sign in first if asked).
  2. Give it a name like Prabhvas admin.
  3. Under "Repository access," choose Only select repositories and pick prabhvas-fashions.
  4. Under "Permissions → Repository permissions," set Contents to Read and write. Leave everything else as-is.
  5. Click Generate token, then copy it — GitHub only shows it once — and paste it above.
  6. Keep it somewhere safe (a password manager). If it's ever exposed, delete it from that same GitHub settings page and generate a new one.
